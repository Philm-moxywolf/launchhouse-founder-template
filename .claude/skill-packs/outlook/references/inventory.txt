# connector exposes: outlook_email_search and outlook_calendar_search were
# already the read tools Launchhouse has actually observed connected on a

# off by default until an organization's Microsoft Entra administrator
# approves the added permission and turns them on in Claude's connector tool
# permissions ("Always allow" is not supported for the send/forward/
# send_draft/event tools). Their behaviour here is documented, not observed,
# and unverified against a real Launchhouse founder's tenant.

# still falls under mcp-guard.sh's own core rules (a read, by name), and is
